# FB Clone Website Dummy

A simple **Facebook-style clone website** created as a dummy project for practicing **Git and GitHub**.

This project is mainly focused on learning how to work with repositories, commits, branches, remote repositories, and other essential Git/GitHub concepts while using a small web-development project as an example.

## 📌 About the Project

**FB Clone Website Dummy** is a basic website inspired by the general layout and concept of social-media platforms.

> **Note:** This project is created strictly for **educational and practice purposes**. It is not affiliated with or connected to Facebook/Meta.

The website can be used as a playground for making changes, creating commits, experimenting with branches, resolving conflicts, and pushing changes to GitHub.

## 🔄 Git Practice Workflow

This repository can be used to practice a typical Git workflow:

```bash
# Clone the repository
git clone <repository-url>

# Move into the project directory
cd fb-clone-website-dummy

# Check repository status
git status

# Make changes to the project

# Add changes
git add .

# Create a commit
git commit -m "Update website"

# Push changes to GitHub
git push
```

You can also experiment with branches:

```bash
# Create a new branch
git branch feature-update

# Switch to the branch
git checkout feature-update

# Or create and switch in one command
git checkout -b feature-update

# Push the branch to GitHub
git push -u origin feature-update
```
